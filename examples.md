# Examples

Real output from CaptionCraft, captured from actual runs.

## Bakery on Instagram

Command:

```bash
python3 captioncraft.py --topic "fresh sourdough" --niche bakery --platform instagram --seed 7
```

Output:

```
Nobody talks about fresh sourdough enough. Time to fix that.

Small batch, big flavour, zero shortcuts. That is how we do things here.

Save this post and tag a friend who would love it.

#CommunityFirst #BakersOfInstagram #SupportLocal #PastryLover #BreadLovers #CakeLovers #ShopLocal #Sourdough #BusinessOwner #BakedFreshDaily #MadeWithLove #SmallBusiness
```
